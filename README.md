## 🚀 Deployment

This website can be hosted for free using GitHub Pages.

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Click **Save**.
6. Wait for GitHub Pages to publish the website.

Your website URL will look like this:

`https://YOUR-USERNAME.github.io/CodeNova-Web/`

Replace `YOUR-USERNAME` with your GitHub username.

## ⚙️ Customization

Before publishing, update the website's configuration with the correct:

- Website name and description
- Contact email address
- App download link, if applicable
- Privacy policy and terms that accurately describe the project

**Important:** Review all legal pages before publishing. Do not publish unverified privacy or data-handling claims.
